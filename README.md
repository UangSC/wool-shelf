# 🧺 wool-shelf · 羊毛货架

精选互联网福利资源导航 —— 一个**纯前端、零依赖、零构建**的静态站点。

把散落各处的「羊毛」整理成一张货架：国产模型 Token、公益中转额度、付费中转优惠、免费在线工具，
一眼看懂「**是什么 → 能薅到什么 → 怎么薅**」。

## ✨ 特性

- **零依赖**：纯 HTML / CSS / 原生 JS，无框架、无打包工具、无网络请求
- **秒开**：全部资源本地化，图片懒加载 + 异步解码，首屏即渲染
- **卡片式信息层级**：名称 / 分类 / 一句话描述 / 福利额度 / 邀请码一键复制 / 使用限制
- **实时搜索 + 分类筛选**：支持中文输入法组词抑制，轻量防抖
- **标签体系**：`API` / `公益中转` / `付费中转` / `国产模型` / `官方应用` 等分级标签，各自独立配色
- **推荐徽标**：金色「荐」字徽标，微光扫过动效
- **可视化卡片管理台**：填表即生成 `data.js` 代码，支持推荐标记、暂时下线、排序、导出
- **隐蔽入口**：页脚图标 1.5 秒内快速连点 5 次进入管理台，直接访问会被静默重定向
- **响应式**：适配 2K / 1440 / 平板 / 手机
- **无障碍**：语义化标签、ARIA、`prefers-reduced-motion` 支持

## 📁 目录结构

```
.
├── index.html          # 首页
├── admin.html          # 卡片管理台（隐蔽入口，需口令进入）
├── css/
│   └── style.css       # 全站样式（含设计 token）
├── js/
│   ├── data.js         # 资源数据（唯一需要维护的数据文件）
│   └── app.js          # 首页逻辑：渲染 / 搜索 / 筛选 / 复制 / 动画
└── assets/             # 站点图标（全部本地化）
```

## 🚀 本地预览

因为使用了相对路径加载脚本，建议起一个本地静态服务器（任选其一）：

```bash
python3 -m http.server 8791
# 或
npx serve .
```

然后打开 <http://localhost:8791>。

## ✏️ 如何添加 / 修改资源

### 方式一：可视化管理台（推荐）

1. 打开首页，在**页脚**找到 🧺 图标
2. **1.5 秒内快速连点 5 次**（慢慢点无效）
3. 进入管理台后，填表 → 生成代码 → 点「⬇ 导出完整 data.js」
4. 用导出的文件覆盖 `js/data.js`，刷新首页即可

管理台支持：新增 / 编辑 / 删除、上下排序、**推荐标记**、**暂时下线**、实时预览。

### 方式二：直接编辑 `js/data.js`

```js
{
  id: "example",              // 唯一标识
  name: "示例站点",
  logo: "assets/example.png", // 放到 assets/ 目录
  color: "#4338ca",           // 图标底色
  cat: "公益中转",             // 分类（自动生成筛选标签）
  desc: "一句话说明这是什么。",
  perk: "$10 额度",           // 能薅到什么
  note: "注册 $5 + 签到 $5",  // 福利说明
  code: "ABCD",               // 邀请码，无则留空
  condition: "限新用户",       // 使用限制
  tags: ["公益中转", "免费"],   // 标签，主分类标签放最前
  url: "https://example.com",
  cta: "立即领取",
  perkLabel: "🎁 新用户福利",  // 可选，默认「🎁 新用户福利」
  featured: true,             // 可选，显示金色「荐」徽标
  offline: true               // 可选，前台隐藏该卡片
}
```

## 🌐 部署到 GitHub Pages

1. 仓库 **Settings → Pages**
2. Source 选择 `Deploy from a branch`
3. Branch 选 `main`，目录选 `/ (root)`，保存
4. 稍等片刻，访问 `https://<用户名>.github.io/wool-shelf/`

> 注意：GitHub Pages 免费账户需要 **public 仓库**；私有仓库的 Pages 需要付费账户，
> 且即便仓库私有，托管出的页面默认仍是公开可访问的。
